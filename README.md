# Chivalrous Landing Page

Create a premium, responsive fragrance landing page for Sarkar’s perfume, CHIVALROUS.

Use the uploaded Sarkar perfume bottle as the main product image. Keep the bottle, packaging, proportions, colour and SARKAR branding completely intact. Do not redraw, recolour, crop, distort or replace the product. Build the page’s visual identity around its deep navy chess-king design.

Overall visual direction

Sophisticated, masculine and regal

Deep midnight blue, black, ivory and subtle silver accents

Editorial luxury-perfume aesthetic

Elegant serif headings paired with clean sans-serif body text

Generous spacing, subtle shadows and restrained animations

Avoid a medieval, costume-like or overly decorative appearance
